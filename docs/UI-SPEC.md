# 当前 TUI 规范

核对日期：2026-10-14。描述当前 React/Ink 全屏界面；验收方法见 [TESTING](development/TESTING.md)，未完成工作见 [STATUS](development/STATUS.md)。设计取舍见[终端舞台](development/designs/2026-10-11-terminal-ui.md)、[阶段执行](development/designs/2026-10-14-task-progress-and-reasoning-recovery.md)与[slash 交互](development/designs/2026-10-12-slash-interactions.md)。

## 舞台与归属

- 默认使用终端备用屏。舞台、轨道和输入区不设背景色，透出终端背景。
- 顶部没有项目页眉或窗口按钮组；当前窗口与快捷键提示在底部状态区。
- 用户、Logox、角色窗口中的普通正文沿各自轨道展示；复制只过滤左侧轨道，角色名、标题、状态、按钮和框线均可选择。
- 系统命令结果、命令错误与模型故障使用灰色文字、灰色轨道和“系统”身份。显示、保存与模型输入由运行时分别决定，规则见[系统提示专题](development/designs/2026-10-13-system-messages.md)。
- 主对话中 Director 回复与角色任务卡共用 Logox 轨道，角色卡标题和底色区分角色。明确 @角色的任务与回复按场景的角色归属呈现。
- 窗口切换、卡片折叠、鼠标悬停、草稿和阅读位置属于界面状态。
- 模型运行过程通过实际思考、工具、回复和 Actor 任务卡呈现；不在对话尾部追加“处理中 / 第 N 次往返”过程块。模型往返次数保留为内部诊断。每次 Thinking 与每个工具是同级内联卡，默认收起，分别保留状态与耗时；不合并成累计 Thinking 卡。
- 失败原因随任务检查点保存，恢复后继续展示 HTTP 状态与可识别的格式原因。服务端可能回显的密钥和请求正文不直接打印；旧记录缺少原因时保持缺失状态，不补造报错。
- 失败与取消留在所属任务位置，默认一行折叠；失败行显示简短原因，展开查看完整脱敏诊断与流程。主窗口 Actor 的故障归到原角色卡，关联的系统故障不另外重复打印，继续对话不把旧错误追加到尾部。

## 卡片与主题

颜色的全局主题由配置目录中的 `config.toml` 之 `[theme]` 定义（`user`, `accent`, `dream_collapsed`, `dream_expanded`），可在用户或项目级覆盖；各 Actor 的高亮色及卡片底色（`card_closed`, `card_open`）由其自身角色文档或档案定义，未定义时由高亮色自动推导暗底；代码回落与默认维护在 [config.ts](../src/config/config.ts) 与 [cards.tsx](../src/tui/cards.tsx) 的 palette，以及 [builtins.ts](../src/actors/builtins.ts)。

- 用户主色默认沉稳深海蓝（`#5282b5`），Logox 执导者与系统强调默认 Claude 暖陶橙（`#d97757`）。
- Actor 底色由其配置文档的 `card_closed` 与 `card_open` 直接决定，默认采用透亮暗底；标题高亮仅改变颜色，不作额外加粗。内置角色包括：Aletheia 澄明冰翠（`#7ee7c4`）、Techne 工匠钛金（`#e5b567`）、Kalon 雅正烟粉紫（`#e8a8dc`）。
- 入梦使用白日梦雾白灰（`#dce2e8`）背景（折叠 `#c4cbd2` / 展开 `#dce2e8`），标题、正文和状态使用深色文字。
- Thinking 与工具标题不加 ›。Thinking 运行头为 `⠦ Thinking... · 1.3s · 124 Tokens`，点阵位于标题前，点阵与流光取所属 Actor 主题色；终态为 `▮ Thought for 13s · 3245 Tokens`，正常结束方块灰色、错误中断红色，主动停止灰色并在详情注明。Thinking 与工具标题默认浅灰，悬停标题时使用所属 Actor 主题色；展开后未悬停也保持浅灰。工具固定前置 `▮`，正常运行／完成为灰色，异常为红色；只显示工具名、关键参数和自身耗时，权限拒绝／拦截追加红色粗体 `Denied`，执行失败追加红色粗体 `Error`，不显示冗长中文异常后缀。收起时透出父容器底色，只在实际图标和标题文字内命中；展开使用独立中性灰底，整块灰底可收起。内层灰底优先于 Actor，露出的角色底色可收起 Actor。
- 左右各 2 列内边距，窄屏按剩余宽度收缩，正文与任务完整折行。
- 场景中的角色卡用顶部 ▄ 与底部 ▀ 绘制对称的半行留白，标题置于中间；长任务可以占多行。卡片之间的空隙独立于点击和悬停范围。
- 展开态保留顶部细缝、正文分组与底部留白。通用活动组件还显示当前阶段，展开显示细节。
- 鼠标移入有背景的收起卡时使用展开态底色，移出恢复；悬停不展开内容、不改变答案。悬停高亮标题时保持正常字重。

角色卡单击折叠，双击进入独立窗口；普通卡单击折叠。鼠标在没有拖动的释放时执行；拖选优先于折叠、停止和回答操作。完整角色名、任务与状态保持可读，窄屏先显示身份/状态，再换行显示任务。

排队、执行、待回答及暂停中的 Actor 卡右侧显示状态与 `■ 停止`，折叠时仍可操作。停止入口平时灰色，鼠标悬停或键盘聚焦时高亮；它与卡片标题、折叠和双击进入分别命中。点击或 Tab 聚焦后 Enter 只停止此任务，显示“停止中…”并禁用；终态移除停止入口。Actor 窗口也显示对应任务卡的状态与停止入口。

## 选择与待回答事项

选择统一用 `❯` 和高亮文字。选中项不更换背景，不使用单选圆点；未选中项为标识保留等宽空位。说明另起一行，与标签正文对齐。

需要人工许可时默认拒绝，只提供本次允许与拒绝。auto 审批模型错误重试一次后，通过所属卡片提供重试或切换模式；模式切换与执行前复核由运行时完成。稍后回答保留请求，主输入仍可编辑；Ctrl+X 取消聚焦的请求。Tab 聚焦场景请求时展开并定位对应卡片。界面回答经运行时验证，界面不执行工具。

正式入口将工具审批及多问题内联到所属活动卡片，选项由真实请求生成；自由回答使用原输入编辑器。角色卡在有待回答事项时默认展开，稍后可折叠，Tab 再次展开并定位。

角色任务出现新的 requestId 时，所属任务卡与请求卡自动展开一次，已有手工折叠不阻止新请求呈现；用户之后可以再次折叠，同一请求的刷新不反复展开。角色完成后更新原卡片，收起标题使用摘要标题，展开先显示摘要报告，再保留完整工作流程。自动交接供 Logox 接续，不追加“你 Actor”或回传行。

正式舞台从角色目录取得身份、颜色和窗口顺序，自定义角色复用相同卡片、草稿和阅读机制；删除定义后仍可查看已有角色记录。卡片展开显示本任务实际模型及转用标记，默认模型不可用的确认属于同一任务；密钥和原始服务错误不进入显示数据。

作品集 demo 的许可、偏好、排队和取消来自 RuntimeStore；主窗口与角色窗口回答同一 requestId。脚本 executor 只展示方案和偏好候选，没有实际修改文件。场景数据投影见[模块说明](modules/README.md)。

## 运行指示与耗时

复杂任务显式登记阶段后，流程按步骤创建时的阶段快照组织。阶段标题相对卡片内容区顶格、段前空一行、所属 Actor 主题色加粗，不使用前缀符号或机械序号；阶段没有卡片或折叠操作。Thinking 与工具同级向内缩进两列，工具继承阶段目的，不重复意图。初始探查保留“梳理目标与制定阶段”，旧无阶段历史不猜测归属；未登记的简单任务不强制展示清单。

Actor 运行卡标题显示自然的当前阶段动作句，右侧保留真实状态及停止入口，不显示 2/4 或恢复次数比例。展开先展示完整原目标、累计思考统计，再阅读报告与流程；续做沿同角色活动链读取原目标。完成标题使用最终摘要。自动恢复显示“接续中／调整中”，所属 Thinking 展开详情保留简短恢复说明，原始思考不改写。

每次模型请求的 Thinking 独立计时和估算 Tokens，默认收起，手动展开不会隐藏同级工具。Actor 累计统计单独放详情，工具执行和审批等待不算思考时间。工具从真正开始到返回计时，排队和审批等待不计执行耗时；并发工具各自在返回时冻结，账本保持模型顺序。审批和提问独立可见。运行时拥有步骤身份、阶段快照与结束状态；等待停止点阵、流光与 Actor 呼吸，恢复后继续，终态冻结。

Actor 的展开与收起底色均轻微呼吸；内层灰底保持独立。共享 80ms 时钟，2.5 秒一个周期，主题色混入底色的比例在 2%～18% 间变化，整张卡片底色和上下半块边缘同步变化，正文和内层灰底保持稳定。普通正文按已有样式段改色，RGB 相同的帧复用行与 ANSI 编码。动画只刷新可见会话画布，固定字符槽和颜色不改变尺寸、阅读位置或选区，不触发整页 React 或运行时快照更新。Thinking 的消息分组与索引按快照、会话和角色缓存，展开、悬停、缩放不重新分组。

## 输入、窗口与滚动

主输入从 1 行增长到最多 5 行，超出后只滚动输入视口并跟随光标；矮终端按可用高度缩小。软折行保持原文，中文、组合字和 emoji 按字形编辑。

每个窗口保存独立草稿和阅读锚点。主窗口 @角色是快速指派，不自动进入角色窗口；独立窗口输入默认给当前角色。提交时记录来源窗口和 activityId；排队即可看到任务，轮到角色后才生成回复。

正式舞台的 Assistant 正文呈现 Markdown：标题和强调使用字重，引用用细竖线与斜体，列表保留层级和序号，代码围栏显示语言与铺满正文宽度的上下横线，过长语言标签保持单行并按字形截断；代码与行内代码使用所属轨道色，链接显示名称及地址。表格按内容需要分配列宽，放得下时不额外拉伸，完整显示顶部、表头分隔和底部框线；超宽时压缩列宽并折行、对齐，列宽不足时纵向显示字段和值。转义竖线和代码内竖线保留为单元格内容。表格框线与实际表宽一致，布局随窗口缩放，保留身份轨道和终端安全边距。代码缩进保留，未闭合的流式围栏按代码显示，未闭合行内标记保留文字。主题、卡片留白和选择符号保持原有规则；用户输入和工具原文按字面显示。

显示行保留内容位置供阅读和选区锚定；复制取屏幕上的文字，保留真实换行并连接纯软折行，不还原 Markdown 标记。账本和模型上下文继续使用原文。阅读锚点保存消息身份和原文位置，新增分片及缩放后保留所在段落；滚轮或 PageDown 到底部后自动跟随，Ctrl+E 直接恢复底部跟随。同一输入批次的滚轮报告累加处理。全屏会话区域缓存排好样式的行，纯滚动平移已有屏幕并补画新行，输入区和状态栏保持原位；Ink 更新和历史恢复在同一输出事务内提交，避免露出清空中间帧；表格和代码的可见框线均可复制；选区在滚动、流式追加和缩放后关联同一内容，拖到视口边缘自动滚动。选中只改变颜色，不改变字距或布局。

## 上下文整理

Actor 自动压缩的过程、结果与错误归入所属 Actor 任务卡，随卡片收起和展开；手动 Actor /compact 归入该次整理卡。

/compact 复用正式舞台的活动和取消机制，整理当前窗口角色。阶段以“扬弃”呈现，运行时负责预算、归档、汇总和保存；TUI 显示结果与错误，不生成摘要。整理期间禁止新任务或模型切换；主窗口 Esc 停止主循环的当前整理，Actor 窗口 Esc 返回主窗口；Ctrl+C 沿用复制与双击退出，Ctrl+D 等待收尾后退出。/status 显示当前角色最近请求占用、水位及输出额度。

## 维护与验收

改样式时同步本文件的当前规则，历史方案留在设计；改变提交、取消、请求生命周期或窗口路由时先确认产品行为并写设计。

自动检查覆盖实际 Ink 的模拟 TTY 接线；字体、透明度、中文输入法和系统剪贴板按真实 Windows Terminal 验收。颜色输出和真实终端观感分别记录。

## 提供商登录

正式舞台输入 /login 时，登录区临时替换普通输入区，上方对话仍可阅读；/login 名称直接进入该提供商 API key 输入。列表按方向键选择，只有标识 ❯ 和文字使用现有 accent 高亮，不改变选中行背景。

密钥使用独立遮罩编辑器，支持输入、粘贴、左右/Home/End、删除和 Ctrl+U 清空。Enter 保存；保存中不重复提交，失败留在登录区。Esc 取消尚未提交的输入，Ctrl+C 提示双击退出，Ctrl+D 关闭；保存或取消恢复原对话草稿。密钥不进入主草稿、交互回答、复制内容、消息或历史。TUI 不拥有认证持久化，只调用 LoginFlow。

## 命令联想

运行时提供的自定义模板命令参与同一 slash 菜单，显示名称与用途；Enter 先补齐名称和参数位置，再提交执行。内置命令名保留，/reload 后候选跟随资源快照更新。资源规则见[资源模块](modules/resources-and-extensions.md)。

正式舞台输入 / 显示当前支持的命令和中文用途，最多五行，方向键选择时列表跟随；矮屏按可用空间缩小。候选在输入区上方，选中项仅使用 LOGOX accent 和 ❯，不改变背景。命令与公开候选见 [commands.ts](../src/commands.ts)，替换逻辑见 [completion.ts](../src/tui/completion.ts)，呈现见 [command-menu.tsx](../src/tui/command-menu.tsx)。

Tab 补齐但不执行；Enter 确认可无参数执行的命令并执行，必填参数的命令先补齐。/model 与 /provider 无参数打开选择器，Tab 仍可补齐成带参数的输入。提供商/模型参数 Enter 只补齐，再按 Enter 提交。Esc 关闭菜单保留草稿，输入或光标位置改变后重新联想；Shift/Alt+Enter 保持换行。候选可见时优先处理选择键，没有候选时保留审批聚焦与原编辑行为。登录密钥、自由回答、多行文本及正文中间的 / 不联想。

application 提供可用提供商名称、当前提供商的已查询模型及目录中的“提供商/模型”候选；界面不读认证、不在键入时查询模型。App 的普通卡片高度在提交布局后测量，相同高度不调用状态 setter；正式舞台没有普通卡片测量节点时保持零值，避免流式更新触发重复测量渲染。

## Slash 选择器与页签页面

[CommandPane](../src/tui/command-pane.tsx) 统一细分隔线、左右留白、固定高度与底部提示；[Picker](../src/tui/picker.tsx) 和 [TabbedPage](../src/tui/tabbed-page.tsx) 共享这个容器。标题、说明、选项/页签、当前项、空状态和完成回调由调用方提供。继续使用 LOGOX 的绿色 accent 与 ❯，没有选中背景。

/model 打开模型选择器，/provider 与 /providers 打开提供商选择器；/login 的提供商阶段也使用 Picker。选择器临时替换输入区，上方保留舞台。键入或粘贴筛选公开候选，Ctrl+U 清空筛选；↑↓、Home/End、PageUp/PageDown 导航，Enter 确认，Esc 取消。Ctrl+C 使用统一双击退出逻辑。模型右侧保留提供商名称，避免同名模型混淆；同族带思考后缀变体（如 *-low, *-medium, *-high）自动折叠合并为基准名，模型列表下方空一行呈现思考强度滑轨（`✦ Thinking: [ ○───●───○ ] tier`），以滑轨位置与色彩区分模型强度（off 灰色、low 澄明冰翠绿、medium 深海蓝、high 暖陶橙、max 烟粉紫、auto 钛金黄），通过 ← → 左右方向键平移滑块调节当前档位，并联动模型条目 `✦ <tier>` 标识与真实模型映射。加载、空列表、部分查询失败和确认失败显示在当前界面；确认成功才应用选择。

/status、/config、/help、/usage 打开同一个全屏页签页面，分别定位“状态”“配置”“命令”“用量”。←→、Tab/Shift+Tab 切换页签；↑↓、PageUp/PageDown、Home/End 浏览内容，各页签分别保留滚动位置。窄屏优先显示当前页签。配置页展示真实生效值，修改其他配置仍通过 config.toml 后重启。

/effort（别名 /thinking、/think）共用选择器，列出当前模型支持的思考档位。确认保存成功才生效；取消恢复草稿。/usage 展示当前会话、当前角色按模型分别记录的任务/汇总输入、输出、缓存和静态费用；TUI 只展示运行时生成的行。

命令界面打开期间拥有键盘焦点，输入不流入主草稿或审批。Esc 返回原角色窗口、草稿、阅读位置与审批焦点；Ctrl+C 使用统一双击退出逻辑，Ctrl+D 关闭应用并中止目录查询。取消不改变模型、不调用模型、不写模型账本。命令状态由 [CommandSurfaces](../src/commands/surfaces.ts) 管理，查询身份和取消信号防止旧响应重新打开界面。

## 状态栏设置

状态栏始终一行，默认按顺序显示角色、模型、思考强度、权限模式、上下文占用、运行状态。权限模式固定提示色：default 灰色、auto 蓝色、creative 紫色；字段保留名称，与 `/permissions mode` picker 和权限页签一致。累计 Token、费用、会话名、项目目录可选；窄屏从末尾收起整项，排序同时决定显示优先级。主窗口显示 Logox 状态，Actor 窗口显示该角色实际任务模型与状态；空闲时显示下一次默认模型，数据缺失显示未统计或不支持。退出确认、复制等短暂提示覆盖这一行，随后恢复；业务结果进入系统历史。

/status 的“状态栏”页签使用 [ToggleList](../src/tui/toggle-list.tsx)：`[ ]` 未选中、`[■]` 已选中，选中文字高亮，`❯` 表示当前焦点，没有选中背景。上下键选模块、Space 开关、左右键排序、Tab 切换页签，Enter 保存并返回，Esc 放弃修改。鼠标点击行开关，行尾 `‹ ›` 调整顺序。保存中禁用编辑，失败保留草案、显示原因，不改变原配置。

/status 的“动效”页签可关闭运行指示、Thinking 流光和 Actor 呼吸；关闭后仍显示静态状态与实时耗时。设置与状态栏布局共同保存到用户 ~/.logox-ts/statusbar.json，旧文件未指定动效时默认开启。

布局保存到用户级 ~/.logox/statusbar.json，所有项目与窗口共用布局，各自填入实际数据。设置页不产生正式任务；损坏的偏好文件保留原样，界面使用默认布局并报告原因。数据接口是 [StageStatus](../src/runtime/stage-status.ts)，持久化由 [StatusbarPreferences](../src/config/statusbar-preferences.ts) 维护。

## 会话切换

正式入口通过 ApplicationStage 订阅运行时会话版本。/new 与 /resume 成功后各窗口草稿、折叠、焦点、选择、阅读锚点和旧画布重置；候选失败或 picker 取消保留当前界面。/clear 清当前显示并重置界面状态，模型上下文与账本保留。/rewind 复用 picker，运行时完成恢复后发布新版本；TUI 只消费新快照与失败诊断。模型/用量/权限页签从当前 getter 读取，资源与 MCP 连接在项目层复用。

/resume 历史项支持 Ctrl+X 删除，选中可删除项时底部显示提示。确认页默认“取消”，明确选择“移到回收目录”才执行；Esc 返回舞台并保留原草稿，选择取消回到恢复列表。当前会话和临时新建项不显示删除提示。操作中阻止重复确认与取消，失败在确认页说明并允许重试；成功刷新列表，不切换当前会话或清空草稿。业务忙碌、占用与回收规则由运行时负责。
